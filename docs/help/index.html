Documentation shortcuts

The help icons inside MetaLoom point here. This page sends you on to the part of the documentation the icon was about.

  • Chat and the AI agent Ask the agent about your media, keep the conversation in a session, and give it skills.
  • Agent memory The notes the agent keeps across conversations, and how to read and edit them.
  • Search Search syntax, filters, and finding material by what it shows rather than what it is called.
  • Uploads Choose where files land, watch a batch run, and keep working while it uploads.
  • Face detection review Review the faces a model grouped together, confirm a group, and give it a name.
  • Reviewing what a model found Confirm, correct or reject the objects and descriptions a model produced.
  • Rating and tagging at keyboard speed Work through a library with the keyboard, one key per rating or tag.
  • Reviewing duplicates Work through groups of near-identical files and choose which copy to keep.
  • Pipeline editing Build a processing pipeline out of nodes and typed ports, run it, and debug a run.
  • Users, groups and permissions Roles, permissions and deciding who is allowed to do what.

Looking for something else? The whole reference is at the documentation, and the search box in the header above covers all of it.
